# برنامج تفتيش السلامة المهنية

نظام متكامل لإدارة عمليات تفتيش السلامة والصحة المهنية في المنشآت الصناعية والتجارية والخدمية، مبني بلغة **VB.NET** ويعتمد على قاعدة بيانات **Microsoft SQL Server** بواجهة عربية كاملة (RTL).

## المميزات الرئيسية

- ✓ واجهة عربية كاملة من اليمين إلى اليسار (RTL).
- ✓ نظام تسجيل دخول آمن بكلمات مرور مشفّرة (SHA-256).
- ✓ إدارة كاملة لـ:
  - **المنشآت** (مع القطاع، النشاط، عدد العاملين، مستوى المخاطر).
  - **المفتشين** (مع التخصص وبياناتهم الإدارية).
  - **زيارات التفتيش** (دوري، مفاجئ، متابعة، شكوى، حادث).
  - **المخالفات** (مع درجة الخطورة والغرامات وموعد التصحيح).
  - **بنود قائمة فحص السلامة** (مصنّفة وقابلة للتخصيص).
  - **المستخدمين** (مدير، مفتش، مشرف، موظف).
- ✓ **التقارير والإحصائيات**:
  - تقرير التفتيشات والمخالفات بفترة زمنية.
  - إحصائيات حسب القطاع والمفتش ودرجة الخطورة.
  - تصدير إلى **CSV** بدعم كامل للعربية.
  - معاينة وطباعة من داخل البرنامج.
- ✓ تصميم MDI متعدد النوافذ.
- ✓ بنود فحص افتراضية جاهزة (الحريق، الكهرباء، الوقاية الشخصية، الإسعافات، إلخ).

## التثبيت والتشغيل

### 1. إنشاء قاعدة البيانات

افتح **SQL Server Management Studio (SSMS)** وقم بتنفيذ السكربت:

```
SafetyInspection/Database/CreateDatabase.sql
```

سيقوم بإنشاء قاعدة البيانات `SafetyInspectionDB` مع جميع الجداول والبيانات الافتراضية.

### 2. ضبط سلسلة الاتصال

افتح ملف `App.config` وعدّل السطر التالي بحسب إعدادات SQL Server لديك:

```xml
<add name="SafetyInspectionDB"
     connectionString="Data Source=.\SQLEXPRESS;
                       Initial Catalog=SafetyInspectionDB;
                       Integrated Security=True;
                       TrustServerCertificate=True"
     providerName="System.Data.SqlClient" />
```

### 3. بناء وتشغيل المشروع

1. افتح ملف `SafetyInspection.sln` في Visual Studio.
2. اضغط `F5` لبناء البرنامج وتشغيله.

## هيكل المشروع

```
SafetyInspection.sln
SafetyInspection/
├── SafetyInspection.vbproj         ← ملف المشروع
├── App.config                       ← إعدادات الاتصال بقاعدة البيانات
├── Program.vb                       ← نقطة بداية البرنامج
│
├── Database/
│   └── CreateDatabase.sql           ← سكربت إنشاء قاعدة البيانات
│
├── Classes/
│   ├── DatabaseHelper.vb            ← فئة التعامل مع SQL Server
│   └── SessionManager.vb            ← إدارة جلسة المستخدم
│
└── Forms/
    ├── FrmLogin.vb                  ← شاشة تسجيل الدخول
    ├── FrmMain.vb                   ← الشاشة الرئيسية MDI
    ├── FrmEstablishments.vb         ← إدارة المنشآت
    ├── FrmInspectors.vb             ← إدارة المفتشين
    ├── FrmInspections.vb            ← إدارة زيارات التفتيش
    ├── FrmViolations.vb             ← إدارة المخالفات
    ├── FrmChecklist.vb              ← بنود قائمة الفحص
    ├── FrmReports.vb                ← التقارير والإحصائيات
    └── FrmUsers.vb                  ← إدارة المستخدمين
```

## قاعدة البيانات

### الجداول الرئيسية

| الجدول | الوصف |
|--------|-------|
| `Users` | المستخدمون وكلمات المرور والصلاحيات |
| `Establishments` | المنشآت الخاضعة للتفتيش |
| `Inspectors` | بيانات المفتشين |
| `Inspections` | زيارات التفتيش |
| `Violations` | المخالفات المرصودة |
| `ChecklistItems` | بنود قائمة فحص السلامة |
| `InspectionChecklist` | نتائج بنود الفحص لكل تفتيش |

### المخطط العلائقي

```
Establishments  ──┐
                  ├──→  Inspections  ──→  Violations
Inspectors      ──┘                  └─→  InspectionChecklist  ←──  ChecklistItems
```

## بنود قائمة الفحص الافتراضية

يأتي البرنامج محمّلاً بـ **20 بند فحص جاهز** موزعة على الفئات التالية:

- 🔥 **الحماية من الحريق** (طفايات، مخارج طوارئ، إنذار)
- 🦺 **معدات الوقاية الشخصية** (خوذات، أحذية، نظارات)
- ⚡ **الكهرباء** (التوصيلات، التأريض، لوحات التحكم)
- 🏭 **بيئة العمل** (النظافة، التهوية، الإضاءة)
- 🚑 **الإسعافات الأولية** (صناديق، تدريب)
- ⚗ **المواد الكيميائية** (تخزين آمن، MSDS)
- 🔧 **الآلات والمعدات** (حواجز حماية، صيانة)
- 📚 **التدريب والتوعية**
